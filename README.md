# c-one · plugin per Claude

Il plugin collega Claude al connettore c-one della tua azienda e aggiunge i comandi rapidi (/oggi, /turno, /settimana, /configura…).
Serve un accesso a c-one: senza, il connettore non risponde. Le istruzioni di lavoro arrivano dal connettore, non da questi file.

Installazione su claude.ai: Personalizzazione › Plugin › Aggiungi › Aggiungi marketplace, incolla l'indirizzo di questo repository, poi installa «c-one» e collega il connettore con l'email di c-one.
